# Faso Live Sport

Mobile-first prototype to follow live and upcoming sports matches in Burkina Faso: football (Ligue 1, Étalons), basketball and handball.

**Live site:** https://draftsman369.github.io/faso-live/

- `index.html` — current prototype (single file, no install, no build step)
- `index-v1.html` — first version, kept for comparison
- `PROTOTYPE.md` — design benchmark, scope, data model and next steps

Scores, players, statistics and articles are fictional, for demonstration. Photos come from Wikimedia Commons under CC BY-SA licenses; credits are shown on each article.
